# ML Inference Platform

A production-oriented ML inference platform demonstrating Python microservices,
REST APIs, ML model serving, MLflow, Docker, Kubernetes, Azure AKS, CI/CD,
and observability.

## Objective

Build an end-to-end customer churn prediction platform where a downstream
application sends customer information through a REST API and receives an
ML-powered churn prediction.

## Architecture

Client → API Service → Model Service → ML Model
